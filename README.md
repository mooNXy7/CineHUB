## 🍿 O que é o CineHUB?

O **CineHUB** é um aplicativo independente desenvolvido com foco em **dispositivos móveis e entretenimento digital**.

A ideia é simples: reunir em uma experiência única **filmes, séries, programação, canais e diferentes conteúdos online**, com uma interface moderna, cinematográfica e fácil de usar.

> **🎬 Um projeto feito para assistir, descobrir e navegar.**

### ❤️ Nossa proposta

**📱 Mobile-first** · pensado para celulares e dispositivos móveis  
**📺 TV-ready** · experiência própria para Android TV  
**⚡ Performance** · carregamento progressivo e foco em fluidez  
**🎨 Identidade própria** · linguagem visual CineHUB, sem copiar outras plataformas  
**🆓 Gratuito** · projeto disponibilizado gratuitamente

## 🎞️ Recursos

- 🎬 **Filmes** — descoberta e reprodução de conteúdos compatíveis.
- 📺 **Séries** — temporadas e episódios organizados.
- 📡 **Programação** — canais e programação de TV.
- 🗓️ **EPG** — guia eletrônico de programação quando disponível.
- 🔎 **Pesquisa** — encontre conteúdos com rapidez.
- ❤️ **Favoritos** — mantenha seus conteúdos preferidos organizados.
- ▶️ **Player** — reprodução integrada para fontes compatíveis.
- 📱 **WEB** — experiência completa no navegador.
- 📺 **Android TV** — navegação otimizada para controle remoto.

## 🌐 CineHUB WEB

A versão **WEB** é a experiência oficial para navegadores.

**🟢 Status: estável e funcionando corretamente**

Ela permanece em sua própria estrutura para que sua evolução não interfira na versão Android TV.

📁 `CineHUB_WEB/`

## 📺 CineHUB Android TV

A versão **CineHUB TV** possui arquitetura própria para televisores e dispositivos Android TV.

Entre os recursos da experiência TV:

- 🎮 D-pad e controle remoto
- ↩️ Botão Back
- 🖥️ Tela cheia
- ▶️ Controles de reprodução
- 🔊 Volume e mute
- ⏪ Avanço e retrocesso
- 📐 Interface adaptada para TV
- 🔄 Atualização do aplicativo
- 🚀 Distribuição automatizada

📁 `CineHUB_TV_Android/`
