# Provider Contract

Providers serão responsáveis por adaptar fontes externas para o formato comum do CineHUB.

Contrato conceitual futuro:

```text
discover()
resolve()
validate()
normalize()
publish()
```

Nesta fase não existe execução automática de providers.

A pasta existe para evitar que as próximas etapas criem scripts soltos e incompatíveis entre si.
